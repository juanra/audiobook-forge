# Audiobook Forge Documentation

A fast, multi-process Rust CLI that orchestrates FFmpeg to convert audiobook directories into single M4B files with chapters and metadata.

## Getting Started

1. [Install](Installation) Audiobook Forge and its dependencies
2. Run `audiobook-forge check` to verify
3. Run `audiobook-forge build` from inside an audiobook folder
