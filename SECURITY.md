# Security Policy

## Supported versions

Security fixes go into the latest release only. Please upgrade before reporting:

```bash
cargo install --locked audiobook-forge --force
```

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/juanra/audiobook-forge/security/advisories/new).
Include the version (`audiobook-forge --version`), your platform, and the steps or
input that trigger the problem.

This project has a single maintainer. You can expect an acknowledgement within a
week. Once a fix is ready, it ships in a new release with a published advisory, and
you are credited unless you prefer otherwise.
